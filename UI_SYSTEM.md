# UI System

The visual language combines high-contrast industrial utility with calm learning focus: deep navy structural surfaces, safety-orange actions, electric cyan progress signals and readable warm-neutral content panels. Tokens define color, type, spacing, radius, elevation, z-index, focus ring and motion.

Desktop uses a persistent sidebar; mobile uses a safe-area-aware bottom navigation. All views support 320px upward, keyboard operation, visible focus, semantic landmarks, contrast-compliant states and `prefers-reduced-motion`. Motion is limited to feedback, progress and navigation transitions; no learning action depends on animation.
